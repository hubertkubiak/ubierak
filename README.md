# Ubierak 🧥🩳

Pogoda + Twój temperament = idealny strój. Specyfikacja: [SPEC.md](SPEC.md).

Aplikacja działa w całości w przeglądarce (React + Vite + TypeScript) i korzysta z darmowych API bez klucza:
Open-Meteo (pogoda, wyszukiwanie miast) i BigDataCloud (nazwa miejsca ze współrzędnych).

```bash
npm install
npm run dev     # serwer deweloperski
npm test        # testy logiki doboru ubrań
npm run build   # build produkcyjny do dist/
```
